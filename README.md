# Student Attendance Management System

## Project Overview
The Student Attendance Management System is a Python-based application developed to manage student records using a graphical user interface (GUI) and a database. It simplifies student record management and helps reduce manual work.

## Technologies Used
- **Programming Language:** Python
- **GUI:** Tkinter
- **Database:** MySQL (as configured in the project)
- **IDE:** Visual Studio Code

## Features
- **Add Student:** Add student details to the database.
- **Retrieve Records:** View saved student records.
- **Delete Student:** Remove student records when required.
- **Database Management:** Store and manage student information.
- **User-Friendly Interface:** Perform operations through a graphical interface.

## How to Run
1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Configure the database.
4. Run the following command in the terminal:

```bash
python gui.py
```

## Conclusion
This project demonstrates the use of Python, Tkinter, and database connectivity to develop a simple application for managing student records efficiently.
